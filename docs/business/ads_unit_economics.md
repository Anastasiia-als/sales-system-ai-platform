## 2. Формули (за ТЗ)

- `CAC = рекламні витрати / кількість нових оплачених клієнтів`
- `CPL = рекламні витрати / кількість лідів`
- `CPQL = рекламні витрати / кількість кваліфікованих лідів`
- `Lead-to-client = нові клієнти / усі ліди`
- `Max CAC = валовий прибуток першої угоди × частка прибутку на залучення`
- `Max CPL = Max CAC × фактична конверсія ліда в клієнта`

## 4. Що означає бюджет $200/міс на практиці

- При CPL $20–40 (реалістичний діапазон для B2B): **5–10 лідів/міс**.
- При lead-to-client 5–10%: **0.25–1 новий клієнт/міс** — тобто клієнт може з'явитися не в перший місяць, і це нормально для тестового бюджету.
- Один оплачений проєкт з автоматизації ($1 000–4 000) окупає кілька місяців тестів.
- Висновки не робити за 1–2 лідами; правило зупинки зв'язки — витрачено 1.5–2 × цільовий CPL без жодного валідного ліда.
