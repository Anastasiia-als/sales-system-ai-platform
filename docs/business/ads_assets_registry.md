## Правила

1. Жоден рядок зі статусом `TO_CONFIRM` не потрапляє в рекламні оголошення, креативи чи лендінги рекламних кампаній.
2. Підтвердження = власниця письмово фіксує: цифри правдиві, клієнт дав згоду на згадку (або матеріал анонімізовано без втрати правдивості).
3. Після підтвердження статус змінюється на `APPROVED` із датою; після відхилення — `REPLACE` (матеріал замінюється до запуску реклами).
4. Нові матеріали додаються лише в цей реєстр, а не одразу в код сайту.
