# Project Notes

This project was created as a real pet project for an AI internship application.

The main goal was not only to build a website, but to model a business process:

- Lead generation and value-proposition positioning
- Service presentation & pricing tiers
- Express diagnostic interactive tool
- Consultation booking flow
- CRM lead statuses & UTM tracking
- Payment status logic (mono, LiqPay, WayForPay, Whitepay)
- Admin dashboard with analytics and RBAC
- AI automation scenarios & QA speech-analytics bot concept
- Mobile-responsive design system and accessibility

The project combines my background in sales operations with AI-assisted product development.

Key learning outcomes:

- How to transform business requirements into clean product structure
- How to work iteratively with AI coding tools
- How to describe complex user flows
- How to design CRM/admin logic and state management
- How to improve UI/UX through feedback
- How to think about privacy and demo data handling
- How to prepare a project for deployment and portfolio review
